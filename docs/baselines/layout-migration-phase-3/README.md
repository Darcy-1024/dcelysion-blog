# 布局迁移第三阶段：普通网格 CSS 变量

## 范围与映射

- 实施基线为 `acabc4ea7b6bef6b1c774586799e0c58a7951640` 加 c55b 中未提交的第二阶段成果。只读参考本地 `upstream/master` 的 `6d82554bfe1cb3d4b43adb0969dad1d43ac6dee3`：沿用纯计算输出变量、SSR 序列化和客户端同源更新的思路；未移植上游的 DOM 自动排栏、`#content-column` 重命名、页脚移出网格或按页型收缩组件列。
- `resolveSidebarLayout(input)` 仍是 SSR/Swup 的唯一状态入口。它将原有启用、页型、左右/双栏、文章临时双栏和特殊 TOC 判定交给 `computeMainGridLayoutVars()` 生成完整变量集合。SSR 在 `#main-grid` 写入变量，Swup 在同一节点逐项更新；没有改动侧栏、音乐、页脚和移动底部的 DOM 顺序与 ID。
- `--main-grid-sidebar-width=17.5rem` 同时控制侧栏轨道和侧栏最大宽；`--main-grid-gap=1rem` 控制网格间距。`--main-grid-cols-md/xl` 控制 768/1280 两级列模板，`--main-grid-{left,right}-display-md/xl` 控制两栏可见性，`--main-grid-{left,right,content,footer}-column-md/xl` 控制列位置。正文和页脚始终同列；特殊 TOC 在文章页保持逻辑左栏到右侧、逻辑右栏到左侧的视觉换位。
- 原 `w-full xl:w-[92vw] max-w-(--page-width)` 外壳、`px-2 md:px-4` 内边距、行模板、移动底部组件和沉浸阅读独立样式保持。沉浸完整变量迁移留待第四阶段。

## 增量验证

- 复用第一阶段 26 条原始测量、16 条补测、42 张截图与第二阶段 6 项纯计算验证、类型/构建及浏览器基线；没有重拍全矩阵。第二阶段播放器原始数据和解释限制已补在其 README：进入前 `scrollTop=74.67, clientHeight=192`，退出后 `186, 111`，不能据此声称精确恢复。
- 本阶段变量语义测试 7/7 通过，覆盖关闭/隐藏、单左单右、双栏平板选择、文章临时双栏、特殊 TOC、变量完整性和缺失组件的旧边缘行为。局部 Biome、`pnpm check`（268 文件，0 错误/警告/提示）和 `pnpm type-check` 通过。
- 一次 `pnpm build` 通过，生成 25 页。文章 SSR HTML 含 `--main-grid-cols-md`；生成 CSS 含网格列、侧栏显示及页脚列变量的消费规则。构建未留下受版本控制的生成文件差异。其后仅修正缺失左组件时的 xl 右栏变量，受影响测试再次通过；站点当前启用双侧组件，构建产物不受该边缘修正影响。
- 生产预览的可核对测量见 [browser-verification.json](./browser-verification.json)。1440 文章直达和首页 Swup 进入都得到 `280 / 700.79 / 280px` 三列，正文和页脚 `x=369.6, width=700.79`，左右逻辑 ID 视觉换位且音频元素为 1。767/768、1279/1280 和 1920 代表宽度确认移动底部、断点与 1600px 外壳上限；1199/1200 的沉浸目录仍分别为 fixed/sticky，退出后普通布局恢复。

## 限制

- 单侧、禁用和缺失组件组合以纯函数测试覆盖，未逐个在浏览器临时改配置。壁纸/主题、所有历史导航组合及播放器精确滚动位置未在本阶段重复验证；播放器退出后仍展开且可滚动的历史结论不等于精确滚动恢复。
- 浏览器预览中文章首次直达继承了此前保存的沉浸偏好；退出沉浸后测得普通文章几何，再从首页软导航复测得到同值。
