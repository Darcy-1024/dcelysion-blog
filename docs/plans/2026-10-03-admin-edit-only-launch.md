3. **按需接入 Waline。** 只核对既有私有实例是否具备本次需要的 management overlay / `003_security_version.sql`；缺失时在上述备份后安装同版本增量并仅重启该私有 Waline。涉及真实评论库触发器/服务，属于本次待批准范围；不自动发评论、邮件、改账号或变更公网采集。回退保留已增加的兼容字段，不用旧备份覆盖新评论。
4. **独立服务与入口。** 新后台容器512MiB、0.5CPU、128 PID、swap不超过内存、uid1000、只读根、cap-drop ALL、no-new-privileges，无Docker socket。复用私有 Waline 回环网络访问方式，数据库连接限定到所需实例，不开放任意外网。独立relay/Nginx监听 `127.0.0.1:18445`，复用现有有效证书、严格TLS，不改共享Nginx/DNS/公网监听。仅挂载已核对包、只读内容和新私有媒体目录。`/ui/profile` 是Waline入口，不填成新后台URL。

6. **回退与保留。** 新入口失败时停止本轮具名容器/独立Nginx/relay，保留新库与媒体供诊断；旧博客、R2、测试环境始终不切换。若本次修改了私有Waline，恢复原固定镜像/配置，保留兼容数据库字段。任何整库回灌须另行决策，不能自动覆盖实际新增数据。不开新备份timer，先保留初始化备份，后续安排常规后台备份。
