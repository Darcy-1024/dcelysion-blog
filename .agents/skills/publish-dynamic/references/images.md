# 动态图片处理与验证

仅在新增或修改动态图片时使用。路径以仓库根目录为基准。

- 保留原始附件。转换前查看源图，保留朝向、色彩、尺寸与可见内容；未经要求不裁切或缩放。
- 用现有工具转为高质量 AVIF（质量约 80 可作为起点），使用不冲突的小写语义文件名，放在 `src/content/dynamic/images/`。
- HEIC 含分块、辅助图或异常尾部元数据时，先用支持 HEIF 的解码器提取并验证主静态图，再编码 AVIF；不使用图片生成替代附件。
- 如果转换会丢失有意义的动画、透明度或用户要求的内容，先明确取舍，再执行依赖该选择的转换。
- 完整构建后，检查当前动态在 `dist/api/dynamic.json` 中的正文及图片顺序；本地图片应解析为 `/_astro/` URL，对应文件须存在于 `dist/`，格式、尺寸和视觉内容正确。
- 比较 `src/constants/lqips.json` 的新增差异，保留此前无关改动。构建因环境失败时说明未完成的步骤，不声称资产已验证。
