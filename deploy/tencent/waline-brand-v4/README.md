# Waline 认证页提示与自动填充样式 v4（待发布）

适用于固定 `@waline/admin@0.34.2`。本目录完整复制生产已引用的不可变 `waline-brand-v3` 资源，仅增加认证页错误提示和输入自动填充的样式修复。`waline-brand-v3` 保持原样作为回滚版本；不要覆盖生产 `/admin-assets/brand-v3/` 文件。

## 本次调整与依据

- 认证页 `.message.popup.notice ul` 使用成对的明暗文字/背景颜色，覆盖固定客户端写死的浅色提示背景。提示文字保留原样，计算对比度为浅色 8.53:1、深色 10.31:1；提高提示层级并允许长错误文字换行。
- 自动填充输入使用对应主题文字、光标和表面色；强制颜色模式使用系统文字色。规则限定在 `.typecho-login-wrap .typecho-login`，不改变保存的凭证和填写行为。
- 保留页头已有用户名、登出与管理导航，不以 CSS 隐藏登录状态。其余登录/注册布局、图片与 v3 一致。

只读核对公开 `/ui/login` 和固定 `/admin-assets/0.34.2/admin.js` 已确认：提示结构为 `.message.popup.notice > ul > li`，原提示背景写死为浅色，用户名与登出按钮由客户端用户状态决定。登录提交的异常统一映射为“邮箱或密码错误”，因此提示本身不能证明凭证校验失败。此目录不改动认证逻辑、异常处理、API、数据库、OAuth、2FA 或验证码；成功后异常来源由认证逻辑修复另行处理。

`wordmark.png`、`wordmark-dark.png`、`favicon.png` 均从 v3 原样复制，CSS 中图像引用保持相对路径。现有显示密码与头像脚本继续使用原注入路径，密码找回/重置页面仍由既有 `password-reset/ui` 资源负责。

## 发布与回滚

当前仅有本地候选资源，尚未部署。`install-waline-brand.sh` 将品牌资源安装到新路径 `/admin-assets/brand-v4/`；三份 Nginx 模板引用 `/admin-assets/brand-v4/theme.css` 与 `/admin-assets/brand-v4/favicon.png`。安装器继续拒绝覆盖同版本的不同内容。

发布时须保留服务器现有认证脚本、Access 与安全配置，备份配置后只合入本次品牌路径变更，执行 `nginx -t`，通过后 reload；不需要重建 Waline 镜像或操作数据库。不能用私有预览模板直接覆盖公网配置。

回滚时将品牌 stylesheet 与 favicon 注入路径恢复为 `/admin-assets/brand-v3/`，执行 `nginx -t` 后 reload。保留 v3、v4 资源供回滚与核对；已发布资源的后续变更仍须使用新版本目录。
