# Waline 普通访客登录样式 v3（未部署）

适用于固定 `@waline/admin@0.34.2`。本目录以不可变的 `waline-brand-v2` 为基础，保留原有后台品牌样式，仅新增访客认证页面的移动优先 CSS。新增页头规则限定在 `body.waline-body:has(.typecho-login-wrap)`，表单规则限定在 `.typecho-login-wrap` 子树；登录后的评论、用户管理、个人资料页继续沿用 v2 的效果。

## 本次调整

- 页头品牌图与语言选择器按可用宽度换行，语言选择器高 44px、字号 16px。
- 登录、注册卡片使用包含内边距的宽度计算，在窄屏保留边距；表单输入字号 16px、高度至少 48px，减少移动设备聚焦缩放。
- 显示上游已有的翻译字段标签，输入后仍能识别字段用途；无第三方登录入口时不保留空白占位。
- 显示密码、记住登录使用至少 44px 的标签点击区；忘记密码、返回首页和登录/注册链接也保留至少 44px 点击区。窄屏记住登录与找回链接可换行。
- OAuth 图标保留链接与顺序，取消上游额外的相邻左边距，通过 flex gap 自动换行。
- 沿用 v2 的系统明暗主题变量，输入、OAuth 按钮使用对应主题表面色。

没有修改上游 JS、页面文字、认证、API、数据库、OAuth、2FA 或验证码行为。现有 `show-password.js` 必须继续加载，CSS 只匹配其 `#show-password-option`。独立的密码找回/重置页面仍由既有 `password-reset/ui` 资源负责；若部署使用上游 `/ui/forgot`，该页共用登录容器，因此适用本目录的卡片与输入样式。

`wordmark.png`、`wordmark-dark.png`、`favicon.png` 均从 v2 原样复制；CSS 中图像引用保持相对路径。

## 发布与回滚

当前为候选资源，生产部署状态需以实际发布记录为准。发布时将资源安装到同源 `/admin-assets/brand-v3/`，引用 `/admin-assets/brand-v3/theme.css` 与 `/admin-assets/brand-v3/favicon.png`。安装器和对应 Nginx 模板的版本引用须一致，保留生产配置、原有认证脚本、Access 及安全配置。上线前备份配置，执行 `nginx -t`，成功后 reload；不需要重建 Waline 镜像或操作数据库。

上线验收应使用实际固定客户端，覆盖登录与注册在 320、375、525px 的明暗模式、语言选择、密码显示、记住登录、忘记密码、OAuth、2FA 和路由往返；确认页面及卡片无横向溢出、关键资源 HTTP 与哈希一致。若生产启用第三方验证码，需额外核实其嵌入控件在窄屏上的自身布局；本 CSS 不缩放、裁切或改写第三方验证控件。后台可复核既有页面没有新样式回归。不要为视觉验收提交真实评论、注册真实账号或更改密码。

回滚时将品牌 stylesheet 和 favicon 注入路径恢复为 `/admin-assets/brand-v2/`，执行 `nginx -t` 后 reload。保留 v2、v3 资源供回滚与核对，不覆盖不可变 v2 文件；后续已上线的样式变更需新版本目录。

## 本地验证

使用从当前公开登录页读取的固定客户端与既有显示密码脚本，在仅监听本机的静态预览中加载 v3；预览 API 返回不可用，不连接生产账号服务。登录页 320/375/525px、注册页 320px 无横向溢出，输入计算字号 16px，显示密码开关与登录/注册路由切换正常。浏览器检查使用系统深色模式；浅色主题、真实登录、OAuth、2FA、真机软键盘及服务器 Nginx 校验尚未验收。图片与 v2 哈希一致，差异空白检查通过。
