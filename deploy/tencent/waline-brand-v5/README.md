# Waline 后台手机页头样式 v5（本地未部署）

适用于固定 `@waline/admin@0.34.2`。本目录从生产使用的 `waline-brand-v4` 完整复制图片与 CSS，再追加共享页头的换行修复及两条后台公告的隐藏规则。v4 的登录页布局、提示明暗配色、自动填充与强制颜色模式修复均保留。

## 本次调整

- 共享 `.waline-header` 允许换行；导航容器清除原有浮动，导航列表按完整标签换行，单个标签不收缩、不拆字。覆盖固定客户端的 ID 选择器和窄屏宽度规则，避免“评论 / 用户 / 导入”被挤成竖排。
- 语言选择、用户入口与退出按钮允许换行，保留全部控件。语言选择器使用 44px 高度、16px 字号和容器宽度上限，去掉外层多余内边距，箭头距右侧 16px，避免手机页头重叠。
- 600px 及以下导航与操作区各自占一行，操作区内部仍可继续换行；更宽屏幕按可用空间自然排布。
- 仅通过 `body.waline-body .upgrade-tips` 隐藏版本升级和 LeanCloud 停服通知。已核对固定客户端 DOM，该类只对应这两种 banner；不隐藏 `.message.popup.notice` 或其他认证、操作错误提示。

`wordmark.png`、`wordmark-dark.png`、`favicon.png` 从 v4 原样复制，CSS 图片路径仍为相对路径。本次不改认证逻辑、API、数据库、OAuth、2FA 或验证码。

## 发布与回滚

本次资源仅在本地，尚未部署。配套安装器与三份 Nginx 模板已统一引用 `/admin-assets/brand-v5/`，保留既有认证脚本、Access 与安全配置；不能用私有预览模板直接覆盖公网配置。安装器继续拒绝覆盖同版本的不同内容。

发布时备份当前配置，只合入本次品牌资源与路径变更，先执行 `nginx -t`，通过后 reload；不需要重建 Waline 镜像或操作数据库。

回滚时将品牌 stylesheet 与 favicon 注入路径恢复为 `/admin-assets/brand-v4/`，执行 `nginx -t` 后 reload。保留服务器已有 v4 资源；已发布资源不原地修改，后续变化使用新版本目录。

## 验证与限制

使用线上固定 0.34.2 客户端与仅监听本机的模拟 API，在 Edge 无头浏览器中验证个人资料页：320、414、768、1280px 下无横向溢出，三个导航标签完整且不拆字，语言、用户与退出控件在屏幕内且互不重叠，两条公告均隐藏；已查看 414px 页面截图。320px 深色模式下中英文语言切换及登录页布局检查通过，按客户端真实结构和显示状态插入的模拟错误提示仍可见。预览拒绝其他外部请求，不操作生产账号或持久数据。

图片与 v4 哈希一致，局部 Biome 检查无错误（保留两条既有、互不相交选择器的特异性警告），差异空白检查通过。本次只涉及部署样式资源与引用路径，未运行博客全量构建。

真实账号登录、评论/用户/导入页各自的业务行为、退出请求、自动填充、真机软键盘、线上资源 HTTP/哈希及服务器 `nginx -t` 尚未验收。不要为视觉验收提交真实评论、注册真实账号或更改密码。
